# Sport Locations App

A React Native application built with Expo that helps users discover and interact with various sports locations. The app shows sports facilities on a map and provides detailed information about each location.

## Features

- Interactive map showing sports locations
- List view of nearby sports facilities
- Category-based filtering
- Location details with ratings and descriptions
- Booking functionality (to be implemented)

## Technologies Used

- React Native
- Expo
- TypeScript
- React Navigation
- OpenStreetMap (via WebView)

## Getting Started

### Prerequisites

- Node.js
- npm or yarn
- Expo Go app on your mobile device

### Installation

1. Clone the repository:
```bash
git clone [your-repository-url]
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Scan the QR code with Expo Go (Android) or Camera app (iOS)

## Development

To start the development server:

```bash
npm run dev
```

To start the web version:

```bash
npm run web
```

## Project Structure

- `/app` - Main application screens and navigation
- `/components` - Reusable React components
- `/assets` - Static assets like images
- `/hooks` - Custom React hooks
